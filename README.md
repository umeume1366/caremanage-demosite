# ケアブル デモ（demo フォルダ）

ケアブルの画面・トーク・通知のようすを、見本データだけで試せるデモです。
サーバー（Cloudflare）にはつながりません。本番のデータには一切さわりません。

## 置き方（GitHub）

1. リポジトリ（caremanage）を開き、「**Add file**」→「**Upload files**」を押します。
2. この **demo フォルダごと**ドラッグして、「**Commit changes**」を押します。
   リポジトリのトップに `demo/` ができ、その中にファイルが並んでいればOKです。
3. 数分たつと、次のアドレスで開けます。
   `https://umeume1366.github.io/caremanage/demo/`

本番の画面（リポジトリのトップのファイル）は、そのままで大丈夫です。

## 通知のようす

上の帯の「新しい連絡」から試せます。

- **📨 画面を見ているときに届く**：通知は出さず、一覧やトークだけが最新になります。
- **🔔 ほかの作業中に届く**：画面のすみに「新しい連絡があります」と通知が出ます。続けて届いても、確認するまでは通知は1つのままです。ブラウザのタブにも未読の数が出ます。

デモでは、ブラウザの本物の通知は使わず、画面の中にカードで再現しています（見る人に通知の許可を求めません）。

## アプリ本体を更新したとき

トップの `app.js` や `style.css` を直したら、同じファイルを `demo/` にもコピーし、
`demo/index.html` の `?v=20261113d` を、すべて同じ新しい番号に書き換えてください。
